## 每一步要填什么

| 字段 | 说明 |
|---|---|
| `id` | 线内唯一，建议直接用下表的承重拍建议 id |
| `eventId` | 承重拍对应的仓库事件 id；玩家焦点正好在这一拍时，卡片直接用主线指南针「去X · 见Y」，可以不写 `hintKey` |
| `when` | 轮到这一步的前提，只许账本路径：`done.*`、`acq.*`（重逢／初见换说法）、`identity.*`（身份决定找谁）、`knows.player.*`（知情门）、`party.*`、`unlock.*`、`line.*` |
| `until` | 这一步已过的条件；不写时 `eventId` 已完成即过 |
| `hintKey` + texts | 玩家不在这一拍时看到的一句：〔去{地点}〕〔找／见{人}〕〔打听／看看／问问{中性对象}〕，≤20 字，不定性、不预告、不点名结果，只用主角已知的名字 |
| `draft: true` | 还没定稿就保留占位并标【待剧情策划】，运行时不显示；定稿后去掉 |

**最低要求**：每条线至少写一条「入口步」（锚已知、还没走进这条线时：去哪、找谁），以及跨地点衔接处（下一拍不在当前所在地）的那几步；同一地点连着走的承重拍，焦点事件的「去X · 见Y」已够用，可以只填 `eventId`。

**现有占位样例**（`draft: true`，正式稿替换）：南荒 `sheyi_look`「去蛇彝村看看」、晋 `palace_ask`「去建康，打听宫里最近有什么事」。
