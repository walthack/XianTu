# 晋宋任务链待定项 · 首版取舍方案

2026-09-19，Codex。状态：供用户评议的设计提案，未批准为正典、未实现、未独立复审。

对应《晋宋任务链改写试稿》§9。用户要求先做一版，因此本稿给出具体方案，不把普通设计问题继续全部留给用户。本稿不覆盖原第三稿的历史审核；以下调整如被采用，需要连同阶段卡重新审核。无运行时、事件ID、canon、隔离状态或存档改动。

## 1. 本版核心取舍

晋线不强造“救驾—查账—封官”的奖励链。本段讲的是：卷入权争、出力却没有分到利益，随后依靠交易建立自己的立足点。宋线讲的是：从守城与粮战进入纸钞合作，再被卷入正式外交责任。

两条线都允许阶段性收束，不要求每个国家最后送一个官职。国家明线的承接必须强，但不把所有发生在该国的商业调查都串成必做任务。

## 2. 晋国终点：先站稳脚跟，不新增晋廷特许

**本版推荐取消晋G作为当前必须补出的终点。** 不授新官、不造全国商权；晋廷特许留作远期候选，而不是当前任务链缺的一块拼图。救驾无所得这一落差保留。

### 晋E末尾增加“交割后的下一笔”（玩法提案）

- 起因：首批粮完成交割，实际合作方需要确认本批欠项以及是否继续合作。只有真实交易完成才出现，不由救驾功劳自动触发。
- 玩家目标：结清本批，决定是否把一次买卖变成稳定合作。
- 发起人：本批实际交易对手；走云氏协作路线则由云氏经手人接洽。不得无论选哪条路都召来云苍峰授奖。
- 首个行动：核实实收、货损、欠款和下一批条件；没有供货能力就不承诺数量。
- 选择一：结清即止。取得本批已结算收入，保留联系人；不背下一批义务，也没有锁定报价。
- 选择二：签下一批有限合作约定。获得该交易对手、该货类、该批次范围内的明确条件，同时承担约定的资金或交期责任。具体金额在实现前依据现有经济尺度定，不生成免费本金。
- 选择三：条款不合，延期再议。已完成的本批不撤销；新增约定尚未生效。
- 失败处理：短交或欠款先按本批合同处理；不得用“合作成功”抹平损失。无法履约时可结清损失退出，后续条件受影响，不重置宫变任务。
- 完成：本批真实结算，并明确继续／不继续的决定。展示“晋国·建康经营篇结束”，而非“晋国线全部完成”。
- 后果：继续合作的条款在下一批报价／交割中实际兑现；不继续仍可日后重新询价。人脉不是对官府的通行权，不免税、不垄断、不支配北府。

这只是有限商业合作，不包装成晋廷官方奖励。国家线后续等待新的国家级矛盾，不为了填满阶段编号硬造封赏。

## 3. 晋F账页：改为可选调查支路，不承担国家线收束

现稿的账页对账桥可以保留为候选，但本版不把“查到广源行”当作晋E之后必然发生的下一章。

- 有已知龙宸线索且有合法取得的具体账页，才出现复核入口；缺一项就不发调查任务，也不显示无法完成的主线目标。
- 玩家在结算时遇到可解释的差异，可先问账房；未有证据时只称“账目疑点”，不能直接命名幕后。
- 愿意查：核来源、对名字、决定公开询问还是私下核验；选择分别影响暴露意图与可公开使用的证据。
- 不愿查：按本批合同完成交易，疑点留在记录里；不影响经营篇结束，不生成“放跑罪犯”的惩罚。
- 缺证：记录未证实，暂不指控；有证：仅调整有证据支持的后续合作安排，不触发晋廷清缴。
- 如后续原著核查仍无晋境账页依据，按“新增可选商业调查”单独评议，或删去该桥。不得继续引用seq 732石见私史证明它。

原稿晋F→晋G的硬性叙事期待在本方案中撤除；这属于新的设计取舍，尚未修改原稿或正式事件。

## 4. 宋C→宋D：用秦桧当面接洽，不再悬着一封请帖

保留原稿的秦桧带见方案，明确它是新增衔接提案，不声称复原了原著送信人。

1. 玩家真实抵达临安并落脚后，在秦桧确实可接触、已有相关知情依据的会面中，由他提出去多宝阁见晴州旧识谈一笔生意。
2. 玩家问“谈什么”，得到有限预告：与钱款流通有关，细节当面谈。不在任务栏提前揭身份或写“取得纸钞发行权”。
3. 选择现在去、问清再去、暂不赴约。暂缓没有无依据的倒计时，之后重新约定；不自动传送。
4. 秦桧不在场则不触发这段，不临时造匿名信使、不远程召来他。玩家继续当前可做的事，待合法会面后接洽；若正式主路缺会面机会，应先补会面承载，不能上线为永久等待。
5. 抵达多宝阁后才展开身份与纸钞议题，按已有授权情节继续。

完成会面不等于发行获准；发行获准不等于已有可用纸钞，更不等于宋军已经退兵。

## 5. 退军与纸钞：先分开记录，查明前不强接因果

按现稿已核证据，保留战场撤退、纸钞授权、后来朝廷消息各自的发生与获知顺序，不新增“两场战争”的解释。

- 纸钞授权完成反馈只写纳税资格／共同监制已成立；不得附带撤军已完成。
- 退军事实只有对应正式事件已合法结算才可展示；消息仅披露，不制造该结果。
- 玩家可能先从别处获知退军，但不能因此倒记亲自守城或纸钞授权完成。
- 原著核查需对照seq 551、578、582、583、593上下文，分别记录军队、地点、命令与实际行动。结果未明确前，不合并事件、不删除阶段、不声称纸钞单独造成战场撤退。

这使本版设计可先成立，但来源核查本身仍未完成。

## 6. 大改史与不参与：本版不新增世界结局

- 帝后死亡IF：不做。救驾中的局部失败只走已有合法失败／重试／撤离合同；若没有可用合同，该支路在落地前必须补设计，不能用正文宣布帝后死亡，也不保证无条件重试。
- 拒任宋使：允许“暂不接受、先问清授权”，不设计永久拒任后由另一人代办的新国家结局。未接受不授职、不替玩家承诺，不显示宋线完成。
- 新场外结算：不做。未启动或答应未到时暂停相关剧情；已进入危机则按该危机合同处理，不能把任务外的任意行动当免费冻结危机时间。
- 已有正式合法结果：仅做兼容披露，不重演、不补个人功劳；结果缺失或冲突时不绕过。

这是当前制作范围的边界，不宣称自由世界已经支持所有拒绝和失败走向。以后扩展世界模拟，应另设计完整替代后果。

## 7. 桥接承载的首版选择

不先发明新ID。以下是待实现时采用的事件划分方案，不表示现有引擎已具备所需合同。

| 衔接 | 首版选择 | 原因与完成边界 |
|---|---|---|
| 夜探后会猎邀约 | 放进夜探后收尾，形成明确邀约记录 | 只表示知道安排；不表示已经赴会 |
| 司空府徐寄改约鹰愁峪 | 独立短桥 | 改了地点与时间，玩家须收到并选择是否赴约 |
| 回建康后因伤暂拒入宫、云氏借将 | 宫变前准备段，保留有序子步骤 | 邀请、恢复准备、借将不是同一回执；暂拒不虚记完成 |
| 发现帝后被劫、决定追湖 | 宫内段收尾加追湖入口 | 先发现失踪事实再出现目的地，出发与抵达分别确认；此处帝后失踪与谢艺生死口径无关 |
| 孟非卿提供临安接头及粮战动机 | 并入赴临安指令段的明确前置步骤 | 原信息获得后才开放相关目标；接头信息不等于玩家已经出发 |
| 秦桧带见多宝阁 | 独立短桥 | 跨地点、同行、有限信息、首次会面均需玩家实际经历 |

若一个现有事件不能保存这些步骤的暂停／读档状态，则拆成最小桥接拍，不以一段总结文字代替玩家行动。隔离关解禁与默认线改挂不在本版实施。

## 8. 评议与落地门槛

本版最重要的新增提议：**晋国经营篇以真实经营成果收束，不强造特许官身；账页调查退出国家必经线。** 其他取舍以原第三稿为底，补清通知方式和范围边界。

若采用本方案，下一步先同步晋D–晋G及宋C–宋D阶段卡、出口表、玩家目标，再复核一次整体承接。随后才做事件合同与原游戏内小段验证，不先另起一个脱离原游戏的demo。

最低验收场景：不查账仍可完成经营篇；不续签不背新债；暂缓赴阁后可合法再约；秦桧缺席不被凭空调来；纸钞授权不结算退军；重复读档不重复交易／授职／奖励；未参与不冒记个人贡献。

以上是提案验收标准，尚未执行测试，不改变P0／B1／G2状态。
