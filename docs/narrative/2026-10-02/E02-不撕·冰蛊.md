# E02 不撕·冰蛊

> 用法：先由 LLM 根据玩家最后一个动作写 1–2 句承接，再接固定文本，人称统一为「你」（程宗扬）。插图 cut-in 用同编号的图片。

**触发选项**：程宗扬买下阿姬曼后，没有撕掉她的身契。

**原著依据**：
- 第23章《赎身》：程宗扬花五十金铢从祁老四手里买下阿姬曼，拿到身契后当场撕成两半，还她自由。本分支改为不撕。
- 第24章《诡计》：苏妲己赏他冰镇酸梅汤，汤里调了冰蛊。蛊虫是透明的，盘在冰晶中，冰化了就在体内四处游动，会冻住心脏、脑浆。她屈指一弹，程宗扬的手臂立刻寒意直透指尖，手指僵硬，皮肤泛出冰块般的光泽。冰蛊加过禁咒，平时不发作，全凭她控制。
- 第26章《潜流》：祁远报告那名天竺舞姬被人用五十金铢买走，苏妲己下令去查买主（原著中凝羽没有揭发他）。凝羽透露，苏妲己原本打算把阿姬曼送往黑魔海。
- 旁证：第118章祁远说中了冰蛊的人会连皮带骨化成水，第121章殇侯用盐水加玄冰掌解蛊，可见冰蛊是从血里往外冻。
- 本结局为原创分支：身契没撕，苏妲己顺着身契查到买主，再催动冰蛊杀人，阿姬曼被锁链押往黑魔海。「你像我哥哥」一句呼应第14、16章阿姬曼对他说过的话。

**固定文本**（汉字 613 字）：

消息来得比你想象的快。祁老四记得买主的模样，凝羽这一次没有替你遮掩。黄昏时分，你被带进画楼，苏妲己斜倚在榻上，指间捏着那张身契。它完好无损，连一道撕痕都没有，是刚从你贴身的衣袋里搜出来的。
“五十个金铢，买走妾身调教了一年多的舞姬。”她笑吟吟地把身契在灯下抖开，“你倒有眼光，可惜不懂规矩。商馆的奴才买下商馆的货，这货归谁，这奴才又归谁？”
你张口想辩解，她却不等你说完，屈指一弹。
起初只是一点凉，从小腹深处浮上来，像那盏冰镇酸梅汤还没化尽。下一刻，那点凉活了过来，开始游动。
寒意顺着血脉往上爬，所过之处，皮肉一寸寸发紧。你低头看见手指泛起冰块般的光泽，想攥拳，指节却僵得发出细碎的脆响。呼出的气变成白雾，凝在眼前不肯散去。窗外还有夏日傍晚的蝉鸣，你却已经冷得听不真切。
你忽然想起那张纸。你曾把它捏在手里，掂量过要不要撕掉。撕了，它只是一把碎屑。没撕，它就是一条铁链。你以为留着它是给自己留余地，此刻才明白，余地从来不在你手里。
冷到了胸口。心跳变得又慢又重，每一下都像敲在冰面上。你跪倒在地，膝盖磕上青砖，竟觉不出疼。
院外传来锁链拖地的声响。你拼尽力气扭过头，从门缝里看见阿姬曼被两名女侍卫押着走过，手腕和脚踝扣着乌沉沉的铁链，红褐色的长发垂在脸侧。她没有哭，也没有看你，碧蓝的眼睛空空的，像两口结了冰的井。
“送往黑魔海。”苏妲己淡淡吩咐，声音里听不出半点波澜。
你想喊她的名字，嘴唇却冻得张不开。她说过你像她哥哥。你连哥哥该做的一件事都没能做到。
寒意漫进脑中，念头一点点变得透明、迟缓，像被封进冰里的虫子。眼前的灯火凝成一团模糊的光晕，然后慢慢熄灭。
你最后听见的，是那张身契被折好、收进袖中的轻响。
