## 结论

R2-11C 的结构化推进从 `s01_05` 扩至 `s01_06–08`。当前四个连续事件均由本地合同提供推进动作；LLM 只演出，不生成动作身份，也不掌握完成真值。

## 三种事件结构

- `s01_06`：确认宫道 → 亲自护送定陶王 → 完成交接并承担护持；全部完成后仍等待郭解事件的绝对截止。
- `s01_07`：核对边警来源 → 标明未经核实 → 选择交给新朝或贾文和的持续联络线；具体交接对象写入 `completionChoices`，董卓事件仍只在绝对截止结算。
- `s01_08`：与阮香凝私下核验 → 区分亲知事实与推断；无硬截止，保持 persistent，完整完成后立即结算。

## 可见时间与确定性收束

右栏现在显示当前步骤、完成进度和剩余重要行动次数。剩余窗口取事件绝对截止、未追踪卡寿命及首次追踪后的六回合上限中的最小值；persistent 事件明确显示“无硬截止，可自行安排”。

绝对截止采用三分法：

- `participated`：完成全部步骤，按既有合同授予唯一权限；
- `partial`：至少完成一步但未完成合同，保留步骤选择、NPC 经历与部分参与回执，不授完整权限；
- `offscreen`：零有效步骤，世界自行推进，不伪记亲历。

`partial` 只描述玩家介入程度；事件世界真值仍按 timeline 场外发生，二者不混账。
