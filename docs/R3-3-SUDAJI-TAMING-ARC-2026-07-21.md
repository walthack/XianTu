## 2. 设计红线：三条会掉价的写法（必须避开）

1. **武力压制翻盘**——正典前期是她吊打主角（武力第一梯队），靠后期修为反超压她，等于承认她只是个数值，与"智商天花板"人设无关。
2. **靠敏感体质的快感征服**——她 weaknesses 有"对性刺激极度敏感、易陷入高潮失控"，这是最容易顺笔写的路，但会把全书妖艳天花板写成普通玩物，且与潘金莲/凝羽/卓云君路数完全重复，差异化归零。该弱点只可作**一次性关键道具**（见第二幕），不可作驯服机制。
3. **爱情感化**——她三条 principles 无一条能通向此处，彻底 OOC。

## 3. 三幕结构：「驯兽师的败北」，作者＝小紫

**设计公理**：两个智商天花板对撞，**谁都不许被写蠢**。小紫不靠骗，苏妲己不靠瞎。小紫做的是她 registry 原文写明的事——"享受作幕后黑手为其铺路"、"常以不经意的点拨让程头儿误以为是自己想到的"：她不赢辩论，她**造局**。苏妲己全程看得见局，仍然只能走进去，因为那确实是最优解。

### 幕一 · 猎物错位（她自己加注）

苏妲己按惯例把程宗扬当玩物收编，手段库（财富、要挟、暴力、性）逐一失效——**不是被破解，是他不按玩物的剧本走**。她开始加注。

- 套牢机制＝她自己的 principle：**「绝不做亏本生意，被骗走的必须连本带利讨回来」**。投入越深越不能收手。她是被自己的规则套住的，不是被人套住的——智商天花板只能这样输。
- 小紫在此幕**只观察不出手**，开始建模：她要的不是杀一个敌人，是收一件作品。
- 正典素材现成：`s08_04 苏妲己入局` → `s08_05 入微突破逼退` → `s08_06 追杀暂退`，加注过程有真实事件承载。

### 幕二 · 把柄的落空（她的预测第一次失败）

她的秘密弱点（失控）暴露在程宗扬面前。在她的世界模型里，这**必然**导向要挟——她甚至已备好反制（毒、暗杀、交易）。

- **结果他没用。** 对"绝不放弃对局面的掌控"的人来说，被要挟不可怕，**自己的预测错了**才动摇根本。这一拍不掉她一分智商，却比任何床戏都致命。
- **小紫的第一笔**：她**预判了程宗扬不会用**（她比谁都懂他），因而没有阻止暴露发生。用自己的男人当不知情的器具——这是她最拿手的活。
- 玩家视角：这里必须是**玩家的真实选择**而非剧情安排（见 §5 失败分支）。

### 幕三 · 托付而非投降（她主动交出掌控）

外部压力落到她的逆鳞上：**残存狐族孤儿**（孙寿/胡情/淖嬷嬷）。压力源须是**世界自身**（吕氏倒台、佛道清洗等既有格局），**绝不能由程宗扬制造**——否则退回要挟，全盘作废。

- 她一生的 principle 是"绝不放弃掌控"，但保护孤儿需要她**放弃掌控、把人交出去**。
- **小紫的作品成型**：她铺的局让唯一安全的港口只剩程宗扬这一边。苏妲己**看得清整座建筑**，仍然走进去——因为那真的是最优解。
- 驯服的形态＝**她自己算出来、明知是此生唯一一笔亏本生意，还是做了**。
- 正典桥：孙寿"吕氏倒台沦死囚→交程宗扬审讯→成其禁脔"是既有事实，可直接作触发。

### 收尾 · 不给答案

最后一拍**不写臣服宣言**。她看的是小紫，不是程宗扬——认的是那件作品的手艺（两个顶级掠食者之间的专业敬意）。对程宗扬的称呼"死奴才"一个字不改。

**谁驯了谁，永远不给答案**——这才对得起正典给的"驯兽师与妖魔的拉锯"定性。

## 4. 小紫的两件作品（对照结构）

| | 卓云君 | 苏妲己 |
|---|---|---|
| 手段 | 玉笙残酷破处 + 种奴印（暴力） | 造局，**一枚种奴印都没用** |
| 对象状态 | 被打碎后重塑（人格分裂） | 全程清醒，自己走进去 |
| 小紫的位置 | 施暴者 | 建筑师 |
| 正典依据 | keyEvents 明载（一部末#134） | 本弧线 authored |

**"不需要种奴印"本身就是这件作品的炫技点**——也是它与卓云君线不重复的关键。两人同在清羽记建康段（stage_09 canon 三人同行），对照有天然叙事邻接。

## 5. 可玩化

- **全库最难攻略对象**：跨关卡多阶段，不得在一关内完成；三幕对应亲密档案 revealTiers 的三层。
- **真实失败分支（硬）**：玩家只要**利用过她的把柄要挟一次**，立刻触发 principle「绝不放过背叛者，尤其是用她名头却背主求荣的奴才」——收编线**永久关闭**且她展开报复。这让第二幕的"不用把柄"成为玩家的真实决策而非剧情安排。
  - 连带后果：**小紫的作品也毁了**——玩家可以亲手砸掉小紫的杰作，这是很好的关系代价（小紫不会明说，但会记账）。
- **分歧账本接入**：收编与否影响建康财富格局（她垄断建康财富）与黑魔海残余势力走向，是天然的跨关回响素材。
- **宿敌系统首用例**：这条弧线是 roadmap「世界/NPC 引擎设计参照系」里**暗影魔多宿敌映射**的第一个真实用例——NPC 记住玩家造成的结果并个人化升级，最终形成个人化终局。

## 6. hardLimits（写作硬约束）

1. 【时序·力量】前期她武力第一梯队、吊打/完虐男主——早期关卡不得写成被压制。
2. 【人设】掌控欲铁律：失控只能是被迫的瞬间，**不是常态转变**；驯服后她仍是掌控者性格，只是**交出了一次掌控权**。
3. 【机制】第三幕压力源必须来自世界自身，**不得由程宗扬制造**（制造即等价要挟，作废全弧）。
4. 【逆鳞】狐族孤儿不得作为亲密场景的筹码轻用；她们是她唯一的软处，只在幕三承重。
5. 【互斥】与吕雉线区分：吕雉是**主动谈条件的交易式委身**（为飞羽族），苏妲己**永远不肯开口求**——设局让人不得不接手，然后自己失去继续掌控的理由。两人不得都写成"为族人低头"。
6. 【互斥】与 IF「莫愁擒妲」互斥：该 IF 激活（她已死）后本弧线不得触发。
7. 【称谓】对程宗扬"死奴才"不因驯服而改；自称"本夫人"。
