## 玩家怎么测

1. 打开主页，点击 **六朝世界试玩**。
2. 首次点击 **建立试玩角色并开始**；之后可选 **继续上次试玩** 或 **重置并重新开始**。
3. 进入正常阅读面后直接自由输入。推荐选项只是提示，不是必须执行的任务。
4. 观察顶部“六朝世界试玩”和右栏“当前局势”：世界回合、NPC 行动、期限与机会会随重要行动继续推进。
5. 若介入郭解或董卓的命运，必须在窗口内采取具体行动、通过本地判定，并在右栏确认正式 IF。
6. 三项局势结算后，顶部显示世界线结果；填写自由感、原著感、因果连贯度并复制反馈摘要。

已有试玩档可以直接选择 **继续上次试玩**，无需重开。载入后会为旧事件快照补齐新增的世界内传信表现，
但不会重置世界回合、事件结果、人物关系或既有正文；已经公开过的事件也不会倒带重演。

试玩约 15–25 分钟，需要“API 管理”中已有的有效叙事 API。零 LLM 的确定性引擎回放仍保留在入口页的技术验收链接中。

## 隔离保证

- 使用固定角色 ID `char_world_sim_playtest_v1` 和固定槽位 `六朝世界试玩`。
- 只有带应用签名 `world-simulation-player-playtest-v1` 的同类试玩档才能被重置；ID 冲突时拒绝覆盖。
- 角色元数据和完整 SaveData 都带 `localOnly` 边界，只读写本机 IndexedDB。
- 远程根元数据会剔除隔离试玩角色并保留原远端活动角色；远程根存在时，启动加载仍会把本机试玩角色合并回来。
- 加载、普通保存、另存、导入／导出、修复、快照、对话前备份、迁移及回滚均沿用本机-only 读写路径。
