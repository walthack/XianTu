## 3. 新快路合同

### 3.1 本地真值先行

- 骰点、结果、气血／门控效果和 Canon Rail 过程边界继续由现有本地判定系统负责。
- LLM 只把已经落账的结果写成场景正文，不得重骰、改结果、补发物品、完成事件或修改存档。

### 3.2 最小 RenderPacket

只允许发送：

- 玩家本轮原始行动。
- 当前公开的地点、时段与极短场景连续性。
- 已落账的 judgement ID、类型、骰点／总值／难度、outcome 与 `appliedEffects`。
- 当前已揭示、确实在场且本轮必要的人物规范名／ID。
- 本轮必须遵守的 Canon Rail 过程边界、精确回执和少量禁止编造项。

禁止发送完整存档、全角色档案、未来事件、未揭示私密知识、全局关系、RAG 召回、长期记忆库、完整 canon、完整命令 schema 或下一拍答案。

### 3.3 单次同模型渲染

- provider、model、temperature 与页面当前选择保持不变。
- 只改变本次调用合同：纯文本、单次请求、`maxTokens=3072` 起步、服务层隐式重试为 0。
- 页面配置的 force JSON 不被永久修改；仅为本次纯叙事调用提供显式 text override。
- 不调用 Step2，不生成命令，不做 RAG／embedding，不做润色，不做 LLM 全量重写。
- 本地校验失败、超时或服务错误时，使用基于已落账回执的确定性安全短文；不得重新调用模型。
- 仍先缓冲并做本地知识／回执校验，验证通过后一次展示，避免把违规半成品流给玩家。
