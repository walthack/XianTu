# R2-10G 机会卡与长期 NPC 记忆 G1

日期：2026-07-20  
范围：确定性机会生命周期、NPC 经历记忆与跨事件消费。

## 结论

机会卡不再是进入事件就常驻的静态菜单。卡片可以由本地已经裁定的 actor/action/knowledge 触发，并经历 `available → tracked → participated/offscreen` 或 `available → expired`。未出现、已过期、已关闭的卡不能追踪，UI 与 prompt 只投影当前可用卡。

NPC 长期记忆从“关系与知识快照”扩为带事件、摘要、标签、显著度和发生回合的经历。行动开始、冲突结果、玩家介入或缺席都会形成可去重经历；每名 NPC 只保留显著度最高的 12 条。相关记忆标签可进入后续行动效用，并随决策回执交给 LLM 渲染，但 LLM 不能自行写入记忆或改分。

## 首批合同

- `s01_07` 边警卡由董卓军令或贾文和退场行动触发，寿命 3 回合；
- `s01_08` 核验卡由阮香凝核验/搜集行动触发，寿命 4 回合；
- 玩家在 `s01_05` 兑现第一道诏令后，贾文和保存显著度 100 的经历；该标签在 `s01_07` 为其保全联络资源行动增加可解释效用。

## G1 自动验收

`tests/r2_10g_opportunity_memory.test.mjs` 验证：

1. 行动触发卡片，未命中触发条件时不提前显示；
2. 世界回合到期后卡片关闭，晚到追踪失败；
3. 参与路线形成长期经历、机会状态与权限链一致；
4. 长期经历跨事件改变候选评分，并出现在决策回执；
5. JSON 重载后只保留最高显著度 12 条；
6. validator 拒绝非法寿命、未知触发引用和坏的记忆效用。

命令：`npm run test:g1:npc`。

## 边界

- 经历摘要只记录引擎已裁定事实，不保存 LLM 自由正文；
- 记忆效用只能使用 Mod 明示标签与权重，不回流任意世界路径；
- 机会过期不等于玩家失败，也不伪造亲历；
- G1 不替代 G2 的真实模型可读性、泄漏与表演验收。
