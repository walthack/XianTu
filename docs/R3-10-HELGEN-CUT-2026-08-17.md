# R3-10 开场切法：Helgen 洞口 · 2026-08-17

> 用户裁定。写进 `mainQuestAxis.ts` 节点表。不要按关改挂。

对标上古卷轴 5：出 Helgen 山洞之后，玩家可以不去河木镇（Riverwood）；但洞口朝前，本能一直跑就会进村。精妙在默认矢量，不在任务锁。

## 强制段（还没进自由世界）

`stage_01` → `stage_02` → **白湖脱身**。

- 地点是五原城白湖商馆（`liuchao.location.baihu_shang_guan`），中州，不是南荒商路。
- `s02_06` 停在「识破苏妲己、被囚、追问霓龙丝」，rail 禁止在这一拍脱身。
- 脱身是下一拍，建议 id：`lcq.event.baihu_shangguan_escape`（**作废** `s03b_baihu_caravan_south`）。
- 主干，不是小紫支线。`stageId` 只是文件落点（`lcq.stage_02`），不参与触发。
- 结束条件：人自由了，还在五原。不传送到蛇彝村。

## 自由世界从五原开始

洞口朝前那条路：

出商馆 → 南门 → 南荒商路（紫溪、黑石滩）→ 蛇彝村。

车马、苏妲己的人、霓龙丝的说法，都堆在这个方向。玩家什么都不想、出门一直走，就进昭南。

回头进城、北上、找人、耗着，都合法。

主轴日志可以写「南边有活路」，作用等于 Helgen 后那句去河木镇：指路，不传送，不锁门。**不要**再加一条主干节点「必须到蛇彝村」。

## 昭南

开门仍是 `lcq.event.s03b_snake_flower_bridge_02`（撞上灭村，知道鬼王峒）。

云氏同行（`s03b_04`）是到村之后的反应，不是入南荒的门票。商队是朝前走时最常见的交通，不是结构必然。

## 冰蛊是状态，不是门

可以留在脱身之后的身上。不解它，五原仍是自由世界。

三槽，都由引擎落账，不靠模型路过编神医：

| 走法 | 结果 |
|---|---|
| 朝前，按答应的南下交差 | 蛊还在，苏妲己暂时不发 |
| 真碰到殇侯（登记：登场于五原；正典解蛊在 `s06_06`） | 蛊解了。完成键跟「见到这个人」走，不跟关走 |
| 拖到毒发 | 开场失败结局 |

期限用「三个月南荒之约」，不用「两日内组队」。两日是旧关卡逼上路的。苏妲己可以催、身体可以示警；到期未交差、未解蛊，进毒发结局。

本轮不新造第三个解蛊人。毒发只在中过蛊的存档上存在。

解蛊完成键＝蛊解了或交差了。到蛇彝村只开昭南，不解蛊。

## 不要做

- 出馆直接站在死村里（等于 Helgen 结束时已经在河木镇广场）
- 把白湖写成南荒路上的锚定拍，或把建议 id 写成 `s03b_*`
- 把「必须跟商队」写回昭南入口
- 按隔离关／可达关改挂来「救」这条节点
- 让 LLM 在乱逛时编一个能解蛊的人
