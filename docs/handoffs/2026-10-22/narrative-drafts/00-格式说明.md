## 2. 字段约定

### 2.1 剧情节点表
| 列 | 含义 |
|---|---|
| 建议 id | 短 id，前缀国别：`nh_` / `jin_` / `song_`…。可对照仓库 `lcq.event.*`，但对齐不强制；本表 id 是剧情策划侧建议 |
| 原著位置 | 书·集·章；能查到写行号。查不到写「未查到」 |
| 一句话内容 | 只写发生了什么，不过度解读 |
| 是否必经 | `是` / `否` / `条件必经`（条件写在依赖列） |
| 依赖 | 分项：`身份` · `熟识` · `知情` · `在队` · `在场`。无则写「无」。在场一律 `待H1:候选…` |
| 交叉依赖 | **必填**（可写「无」）。见 §2.4 |

### 2.2 可变体节点表
| 列 | 含义 |
|---|---|
| 节点 id | 与剧情节点表同一 id |
| 触发条件 | 方案二四读：`acq.*` / `identity.*` / `knows.player.*` / `party.*`；可组合。在场写「待H1」 |
| 变体分支简述 | 命中条件时怎么讲；标【原创】的是非原著入场 |
| 默认走原著 | 缺条件时走哪条（通常＝原著正文） |
| 对后续影响 | 只写结构影响，不写文案 |
| 状态 | `已定套入` / `待用户`（必须附推荐） |

### 2.4 交叉依赖（13:35 新增）
每个节点必须交代与**其他国线／本线其他节点**的先后关系，三选一写法：
- **表内加列**「交叉依赖」（样板③宋起推荐）；或
- **独立小节** `## 3. 交叉依赖`（样板①南荒可增量补，避免整表重写）；或
- 变体表「对后续影响」列写不下时，在交叉依赖里写结构影响。

交叉依赖应写清：
1. **若先走了**某国／某节点：本节点的身份·熟识·知情·在队如何变；
2. **若后走**某国：对本线后续的影响；
3. **跳过**路径（尤其跳过南荒、跳过晋）时的默认分支（指向变体表 id）。

无跨国牵扯时写「无」。
