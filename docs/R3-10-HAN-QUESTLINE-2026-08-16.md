## 0. 口径

### 0.1 这条线写什么

汉国线＝洛都权力归属怎么换手：

程入局（官身＋田）→ 天子削豪强（限田，云家被卷）→ 天子暴毙、真空 → 吕氏专权对上刘建举兵 → **玩家选边，决定出不出面拥立定陶王** → 董卓入京 → 刘建败、诸吕自裁 → 新帝登基，程以辅政定型 → 以汉使离洛。

**不写**谁守哪座宫、哪个内侍被诛、哪支番号叛投。那些留在 143 条逐拍 `objective` 里。

### 0.2 人物层级（本轮硬纪律）

判据与主轴同构：**此人的进退是否改变权力归属**。改变的可点名；只执行别人意志的，不上任务链。

| 可以点名 | 不要点名 |
|---|---|
| 天子（刘骜）、外戚（吕冀）、太后（吕雉）、宗室作乱者（刘建）、被拥立者（定陶王）、入京军阀（董卓）、后宫（赵飞燕／赵合德）、玩家（程宗扬） | 内侍、家将、帮会、某某司马、「招牌登场」那一批，以及任何只出现一两拍的执行者 |

节点正文已自查：不出现中行说、徐璜、左悺、唐衡、具瑗、蔡敬仲、程郑、洛帮、鹏翼社、越骑军司马、班超、阮香凝、成光、齐羽仙、冯子都、吕奉先、吕巨君、霍子孟、贾文和、友通期、秦桧、郭解、金蜜镝。云家只作家，不作家将名。

### 0.4 线是叠加层

**核实**：37 关是 `nextStageId` 单链。`transitionToNextScenarioStage` 遇到隔离关会沿该关自己的 `nextStageId` 静默越过。`lyl.luoyang_coup` 在名单里，`nextStageId`＝`lyl.han_palace_endgame`。


### 2.1 H4 为什么要新 event

**核实（timeline）**：

- seq 839：算缗奏疏被塞进限田限奴条款（仍在 `luoyang_cloud_secret` 窗口 777–884 内）。
- seq 875：天子先收算缗、暂缓限田。
- seq 885：程与云家用纸钞买下一千五百顷田。
- seq 888–889：内朝通过限田令，云家被牵连。

**核实（事件层）**：全库四字段无「限田」「一千五百顷／每亩四金铢」。885–889 落在被跳过的 `luoyang_coup` 窗口（885–899）。839／875 虽在可达关窗口里，也没有对应 event。

限田通过改变的是**田与奴婢归谁、天子能不能削豪强**，不是执行层流水。不上链，H3 之后会直接跳到「吕冀已重伤」，天子刚动过刀这件事在世界里不存在。

**推断**：压成 **一条** 挂在仍加载的 `luoyang_cloud_secret` 末尾（`s05_09` 之后）。axis 会略超出本关 `axisSeqHi=884`——标清楚即可，不要为它新开或放出下一关。四字段只写：纸钞买田、限田令起、云家被卷；不写谁在朝会上提案。

## 3. 硬缺口：seq 891–899（缺的是获知，不是亲历）

### 3.1 现状（核实）

`lyl.luoyang_coup` 窗口自称 885–899，8 条 event 都在。默认线整关不加载 → 这些 event **不存在** → 没有 `occurredAtTurn` → 玩家连「天子死了」都无从听说。下一关 `han_palace_endgame` 开场文案已是「政变余波尚未平息」，第一拍 `…_01_beat` axisBeat 起手就是「吕冀被刺十七刀」。

用户举例（seq 893 藻井目睹）不必做成可玩桥段。引擎已把发生／公开／玩家获知分开（`ScenarioEventTimelineState`；裁定 #113：未获知的场外事实不得进 prompt）。world-sim overlay 里政变关已有「宫里丧讯对不上／含光殿突然清场／密道口灯火连夜」——**关卡不加载，这些局势也不会响**。

### 3.2 权力层只有三件事

| | 事实 | timeline | 不要写成 |
|---|---|---|---|
| ① | 天子暴毙；吕冀趁乱据了含光殿 | 890–891 | 谁勒了谁、谁藏在藻井上 |
| ② | 刘建矫诏起兵，打下南宫与武库、围住北宫 | 894、896 | 哪支军叛投、谁守台阶 |
| ③ | 玩家有没有参与拥立的机会 | 895（程出宫定策） | 召集了哪些帮会／家将 |

第 ③ 条：**玩家可以不参与，但不能像现在这样——拥立自己发生了、玩家事后才知道。**

### 3.3 处置（推断，只此一路）

不放出 `luoyang_coup`，不重写九拍。把三件事挂在**下一道必经的可达关** `lyl.han_palace_endgame` 开场：

1. **`lyl.event.han_power_vacuum`（①＋②，一条）**  
   切进本关即结算为已发生。默认 `outcome: 'offscreen'`。公开与获知走既有三时刻：街巷丧讯、宫门换防、南宫易手——只写权力结果。玩家不必在场。  
   `han_palace_endgame` 已有 baseline 局势「吕冀营帐风紧」；本条是它的**前因**，应写在 `_01` 之前，并给 opening 一句既成事实，避免第一拍假定玩家已知。

2. **`lyl.event.han_sponsor_dingtao`（③，一条，必须可玩）**  
   world-sim 局势：出面拥立定陶王／按兵不动。  
   - 出面＝玩家主导定策，后续 H8 是公开承认，不是第一次听说。  
   - 按兵＝不当操盘手。默认世界仍把继统落到定陶王——**核实**：`lyg.dingtao_beijing` 硬锚点 `anchor.lyg.dingtao_political_succession` 已经这样写（G0／裁定 #154）。不参与 ≠ 改写帝统。  
   H8 `s01_05` 已有「可介入程序与站位，也可让世界自行完成拥立」。H6 管的是**真空里站不站队**；H8 管的是**新朝把继统公开落地**。两拍不要并成一句「拥立已经发生」。

3. **与 IF 进过政变关不双演**  
   若 `s06_01`／`s06_02` 已完成：H5／H6 视为已满足，不再重演。IF 玩家亲历了，默认线玩家靠传闻＋选择，权力结果同一套。

**取舍**：事实挂终局关开场，而不是挂在 `luoyang_cloud_secret` 末尾——该关轴只到 884，暴毙是 890；买官／劫镖章尾突然死天子，时间错位。限田（H4）仍挂买官关，因为它的种子（839／875）本就在那扇窗口里。

不采用「只改 opening 旁白、不建 event」：旁白进不了 `occurredAtTurn`，prompt 门禁仍会把「天子已死」挡在未获知之外。
