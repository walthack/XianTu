# R2-10F 地区／势力／人物分层唤醒 G1

日期：2026-07-20  
范围：确定性状态层，不含 LLM 演出验收。

## 结论

世界演员不再要求每个事件中的全部 NPC 每轮同时计算。决策核现按五档预算唤醒，并将每名 actor 的 `awake/reason` 写入 `wakeAudit`；相同角色状态、世界上下文和轮次得到相同哈希与相同结果。

## 五档合同

- `local_critical`：角色在场或事件地点命中时唤醒；
- `faction`：按 2–5 回合 cadence 唤醒；
- `offscreen_critical`：重大事件首轮、议程升级拍或 cadence 到期时唤醒；
- `minor`：只有在场、被机会点名或所属势力受影响时唤醒；
- `group`：所属势力受影响且 cadence 到期时唤醒。

在途 `activeAction` 优先于分层预算，保证多回合生命周期不会因休眠卡住。未声明 `wake` 的旧 core 保持每轮唤醒，避免存档和旧数据行为突变。

## 首批数据

- `s01_06`：郭解=`local_critical`，剑玉姬=`offscreen_critical/3`；
- `s01_07`：董卓=`local_critical`，贾文和=`faction/3`；
- `s01_08`：阮香凝=`local_critical`。

运行时上下文只取当前锚点地点、在场人物、事件/压力势力、玩家已追踪机会和重大事件首轮。休眠人物不产生决策、不消耗资源、不推进议程；提示词只获得“不得替未唤醒角色新增主动行动”的通用约束，不泄露休眠角色身份。

## 自动验收

`tests/r2_10f_layered_wake.test.mjs` 覆盖：

1. 本地关键与场外关键人物在同事件中的不同预算；
2. 势力 cadence、次要人物相关性、群体 cadence；
3. `activeAction` 经 JSON 重载仍强制唤醒；
4. 上下文进入输入哈希，轮次变化可审计；
5. validator 拒绝越界 cadence 与未知地点/势力引用；
6. 无上下文旧调用保持全员唤醒。

执行：`npm run test:g1:npc`。

## 边界

本阶段只控制“谁在本轮获得计算预算”，不改变事件时间线、Canon Rail、机会奖励或 LLM 权限。它为后续跨书扩量提供成本上界，不代表 G2 真机演出已经通过。
