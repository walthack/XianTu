# R3-10 商队经营层设计稿（2026-08-16）

> 用户裁定（2026-08-16）：**商队不是一条线，是经营层**——「随着你在其他地区的声望／地位上升，
> 获得更多的资源／消息／人脉」，**和普通的公会线不太一样**。
> 故从 `docs/R3-10-SECONDARY-LINES-2026-08-16.md` 摘出，单独成稿。
>
> 状态：**设计稿，未实现**。本轮只登记结构与缺口，不写代码。

---

## 1. 它和另外两类的分工

| 层 | 单位 | 玩家做什么 | 产出 |
|---|---|---|---|
| 主轴 | 王哲三托付 | 六阳祭祀＋保住岳血后裔 | 通关资格 |
| 公会线 | 势力 | 加入组织、做它的事、往上升 | 身份、权限 |
| 城市线 | 地域·关卡组 | 卷入当地政局 | 国家机器（称帝线资源包） |
| **商队经营层** | **跨地域** | **不直接做任务**——它把你在别处挣到的地位兑现 | **货源、消息、人脉** |

**关键区别**：公会线是"投入换晋升"，商队是"**别处的地位在此处折现**"。它自己不产出任务，
是个转换器。所以它不该和公会线／城市线并列成第三条线，而是叠在它们之上的派生层。

## 2. 数据现状（已实测）

### 有的

| 项 | 位置 | 说明 |
|---|---|---|
| 全局声望 | `角色.属性.声望`（num） | 带档位（籍籍无名…）；prompt 有兑换指引（救人除害 +30~300、斩强敌 +100~1000、震动一方 +200~2000，恶行记负） |
| 势力声望 | WorldFaction schema `声望值: num[-100~100]` | 另有 `可否加入`／`加入条件`／`加入好处` |
| 宗门身份 | `社交.宗门.成员信息` | `职位`／`贡献`／`声望`／`加入日期` |
| 地域枚举 | `canon.locations[].region` | 宋国 392／南荒 201／唐国 150／汉国 120／昭南 90／海上 90／晋国 60／秦国 60／太泉 60／塞外 31 |

### 缺的（这层要成立的前提）

1. **声望是一个全局单值**。实测存档 `角色.属性.声望 = 0`，`社交.势力` 为空——
   **没有地方记「在临安你是什么分量、在洛都又是什么分量」**。而用户要的正是"在**其他地区**的
   声望／地位上升"。缺分地域立足度就没有这一层。
2. **没有兑换规则**：立足度 → 具体产出（货源与价差／消息灵通度／能引荐到谁）之间没有任何映射。

**两样都是新机制，不是盘点能盘出来的。**

## 3. 商会类势力的事件层支撑（已实测）

| 势力 | 事件层关数 |
|---|---|
| 程氏商会 | 3 |
| 白湖商馆 | 2 |
| 威远镖局 | 2 |
| 云氏商会 | 1 |
| 广源行 | 1 |

**支撑很薄。** 这反过来印证了不该把商队做成公会线——按公会线的入选门槛（事件层 ≥4 关）
它一条都进不去。作为经营层则不需要关卡支撑，它吃的是别处的地位。

## 4. 提案结构（未实现，待裁定）

### 4.1 分地域立足度

按 `region` 枚举建表（宋国／南荒／唐国／汉国／昭南／海上／晋国／秦国／塞外；太泉不计，非人间地界）。
每地一个立足度值，来源：
- 该地城市线的进展
- 该地公会线的身份
- 在该地发生的扬名／败名事件（复用现有声望指令，但落到地域而非全局）

### 4.2 兑换产出（三类，对应用户原话）

| 产出 | 由什么决定 | 形态 |
|---|---|---|
| **资源** | 该地立足度 | 货源可得性、价差、补给上限 |
| **消息** | 该地立足度 ＋ 当地公会身份 | 能提前听到的征兆层级 |
| **人脉** | 该地立足度 ＋ 关系网 | 能被引荐给谁（接 `acquaintanceLedger`／相识账本） |

### 4.3 与续写段的接口

蓝图 §11：称帝线与商贾线「只是资源包不同」。
- 称帝线资源包 ← 城市线（国家机器）
- **商贾线资源包 ← 本层的累积产出**，而非某条商会公会线
- 终敌帛系（广源行＋蕃密＋晴州）是本层在续写段的对手：**同类玩法的满级对照组**
