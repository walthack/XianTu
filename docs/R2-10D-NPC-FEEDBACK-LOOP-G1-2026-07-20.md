# R2-10D · NPC 态度／知识／effects 反馈环 G1

- 日期：2026-07-20
- 基线：R2-10C 世界时间与 `s01_06–08` 跨事件 G1
- 范围：`lyg.event.s01_05–08`
- 结论：**确定性反馈环 G1 通过；下一里程碑为行动冲突、反制和多回合生命周期。**

## 1. 状态合同

NPC 决策状态新增三条确定性反馈边：

1. `requiresKnowledge`：角色缺少声明的知识条目时，候选行动在评分前直接淘汰；
2. `utility.relationships` / `relationshipRequirements`：`-100..100` 的少维度态度进入效用或阈值资格；
3. `stateEffects`：获胜行动可对白名单资源、当前承重角色间态度和本事件知识词典作确定性增减。

每个知识条目声明 `text/access/evidence`。决策回执只投影行动者实际拥有的 `knownFactIds`，不会因为后台词典存在秘密就把秘密交给 LLM。LLM 仍只渲染裁定结果，不能写回上述状态。

## 2. 跨事件边界

- 跨事件只继承承重 NPC 的 `relationships` 与 `knowledge`；
- `influence/wealth/troops/intelligence` 仍由每个事件局部初始化，禁止演化成全局经济或兵力模拟；
- 旧存档配置迁移时，只接纳新事件知识词典中声明的 id，旧版自由文本不会混入新知识图谱；
- `actorMemory` 经 JSON 存档往返保持，事件切换和重载均不重复结算。

## 3. 首批样本

|---|---|---|---|
| `s01_06` 郭解／剑玉姬 | 护送路线、换防规律尚未知 | 护持／破坏行动分别产出局部知识并改变敌意／敬重 | `escort_witness`、`block_road` 从知识淘汰变为合格 |

## 4. G1 断言

命令：`npm run test:g1:npc`

- 同一输入仍字节级确定；
- knowledge 缺失在评分前淘汰，并写明 `knowledge:<factId>`；
- 态度改变会改变候选得分，数值钳位在 `-100..100`；
- `stateEffects` 不修改正典配置原对象；
- 秘密知识不因词典存在或可见行动而进入决策回执；
- `s01_05` 反馈经事件切换、JSON 重载进入 `s01_07`；
- validator 拒绝未知知识、非活动角色状态写入和非法资源通道。

G2 仍负责真实模型演出、泄漏与玩家可读因果；本里程碑不改变共享服冻结裁定。
