- `npm run type-check`、`npm run build:single`、`git diff --check`：通过。
- 新增回归 `tests/run5Repairs.test.mjs`：谈判边界、共享截止、截断恢复超时、带外部signal的回合取消、世界副本去重、主角目标排除。原取消测试相应要求调用立即拒绝，仍验证底层忽略取消的迟到响应不能消耗B预算。
- `scripts/smoke-run5-repairs.mjs`：隔离浏览器、拦截模型与服务器存储；验证兜底提示、分类异常／10秒挂起后的输入及焦点、实际请求推理参数、另存→重置→手动档可读。
- `scripts/smoke-run5-late-during-b.mjs`：A挂起→离开→B挂起→A迟到→B完成；A不能清除B忙碌状态或覆盖B正文。属于受控HTTP与浏览器证据，不冒充真实模型连续游玩。
- 当前真实OpenRouter主模型的两次独立合成分类探测：`none`30.75秒、`low`27.13秒，均stop／可见41字符／正确选项，completion163、reasoning149。请求未使用新UI截止；样本不同于连续游戏，不证明禁用推理、不证明30秒SLA。官方参数说明：[OpenRouter reasoning tokens](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)。

最终两组脚本均在开发服8091与单页构建服18097通过。初次开发服测试遇到构建同步导致页面刷新；一次卸载即时断言在页面切换未完成时读到忙碌，脚本补充等待输入框卸载／忙碌清除后两服复跑通过。构建生成的registry只变化版本／时间戳，已核对内容完全一致并去除该无关差异。

验收日志保留在 `/tmp/xiantu-run5-*.log`；模型探测仅保存脱敏元数据，不交付密钥。浏览器脚本拦截服务器存储，不产生正式save-storage写入。

## 本轮保留事项

1. **真实模型性能未通过。** 需至少20个不同实际模型回合复测；报告点击到可继续操作的墙钟、失败分母、P95、截断及重试数量。新的超时也计性能失败，不能删除慢样本。
2. **凝羽关系一致性待复测。** 区分口头答应、关系身份、记忆、好感与跨阶段继承；现有档不从好感92自动迁移成亲密关系。
3. **偏离值及世界打断频率未改规则。** 已核实偏离评分含停滞回合／陌生专名／已知实体，世界行动另由每3回合、低张力或失败判定调度；“没有推进主线”与“玩家正在进行有意义交谈”应由系统／剧情共同设计，不能靠降低阈值或压掉真实到期事件收口。
4. **动作文案泛化、固定道具索要／重复发放、长线提示词增长**仍需下一小批专项；拒赌回执／既有期限／路线结果不因本轮改变。
