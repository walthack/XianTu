# 星月湖第一纵切：谢艺死亡／生还二态合同

> 状态：**APPROVED_FOR_IMPLEMENTATION**（2026-08-31）。  
> 权威设计仅此一份：覆盖旧三态合同，不另开第三份。I1+I2 先落地判定地基与命运映射；I3/I4 下游另批。  
> 主题：**死人留下遗产，活人留下证词。**

可达载体：`lcq.event.xieyi_entrustment`  
冻结语义锚：`lcq.event.s06_03` + `qingyu.116.1` + `lcq.if_xieyi_longrest`

## 0. 已拍板的六项

1. **保护＋调查都要落账，玩家只选一边。** 孟非卿当场确定秘密转移方案，并开启生药铺／联络泄漏调查。玩家选择参与其中一边，另一边由 NPC 承担。只确认「他还活着」不算完成（#91）。
2. **longrest 不交割名下之物。** 第一纵切内始终归谢艺。以后只能由清醒后的谢艺授权具体使用，不得称为继承。
3. **乐明珠不在场则救治关闭。** 第一批不增加替代医者、丹药或玩家单独运功救活。
4. **救治占一回合，但不是 1/2→2/2→第三拍。** 开场自动演出找到谢艺与核心托付；本回合二选一，各耗时 1。
5. **ally +8 与神识消耗按草案采用，属可调数值，不进 canon。** 真机后再调；不得为某个结局现场改骰。
   - 补充（2026-10-02，裁定 #168）：战前「此前支援」因子 **+2**，与乐明珠 +8 分列，同属可调数值。只认 `s05b_09_temporary_pact_with_xiaozi` 已结算的 `support_xieyi_counterstrike` 回执；只计一次；掷骰前在判定卡公开；已掷后不可补加。支援不替代医者、不单独救活，乐明珠在场要求（第 3 条）不变。
6. **成功后无第二次 UI 确认。** 内部可两阶段校验，须在同一事务里自动完成权威映射。

## 1. 固定锚与分叉点

### 1.1 固定主线（两态共用）

| 拍 | 权威结果 | 禁止写入 |
|---|---|---|
| `lcq.event.slay_dragon` | 仅龙神死亡 | 谢艺命运、托付完成、骨灰、名下移交 |
| `lcq.event.xieyi_entrustment` 开场（自动演出，无玩家步） | 找到重伤谢艺；听见核心托付「把小紫带往星月湖」（王韬／孟非卿／萧遥逸） | 尚未结算死／生；不得改托付对象 |

云苍峰见证托付。补心丹仍是**拒用**物件，不得当救命条件，不得发明新药。

`xieyi_entrustment` 两态都会完成：固定事实是托付，分叉事实是谢艺命运。不要用带死亡预设的 `xieyi_last_words`，也不要把 `stage_05b` 写进新 ID。

时点：`slay_dragon` 之后，散峒／弑母余波之前。`lcq.stage_06` 保持隔离。`s06_03` 不改名、不迁语义。

### 1.2 当前回合的二选一（各耗时 1）

开场自动演出结束后，界面只给：

- **【承接】陪谢艺把话说完** → 默认正典死亡，无骰。
- **【救治】让乐明珠施针，我运功护持** → 一次可见 `cultivate` 判定（乐明珠须在场）。

| 路径 | 命运 | 冻结映射 |
|---|---|---|
| 承接 | `dead` | `s06_03` **done** |
| 救治 `success` / `great_success` / `perfect` | `longrest` | `s06_03` **void** + 状态 `longrest` + 本判定为接地证据 → `lcq.if_xieyi_longrest` |
| 救治 `partial` | `dead` | `s06_03` **done**；过程：争取到补完遗言的时间，人仍死 |
| 救治 `failure` / `critical_failure` | `dead` | `s06_03` **done**；抢救失败 |
| 取消判定卡 | **不变** | 回到上述二选一，不收束命运 |
| 离开场景或执行无关行动 | `dead` | `s06_03` **done**（默认收束） |
| 已掷出的结果 | 锁定 | 取消／读档／retry **不得重骰** |

本纵切**不生成 `missing`**。`world.xieyi_absence.active` 仅旧档／隔离兼容。

## 7. 存读档、取消、禁止重骰

| 规则 | 合同 |
|---|---|
| pending | 至多一条；读档后仍可确认、改做或取消 |
| **取消判定** | 无骰、无神识、无命运变化；**回到二选一** |
| 明确【承接】 | 默认死亡 |
| 离开／无关行动 | 默认死亡收束 |
| 已掷出 | id 锁定；取消、读档、retry **不得重骰** |
| 此前支援回执 | 随存档保存；取消、读档、重试只按回执布尔计一次，不叠加；已掷后不得补加（裁定 #168） |
| 成功映射 | 同一事务内自动 void `s06_03` + longrest IF；无第二确认窗 |
| `s06_03` | 已 done 不再 void；已 void+longrest 不再写成 done |
| 隔离 `stage_06` | 见映射回执则禁止再演辞世 |

判定引擎不写 `剧本模组.flags`。flags／IF 在 resolution 之后由对账写入，与骰同事务提交。
