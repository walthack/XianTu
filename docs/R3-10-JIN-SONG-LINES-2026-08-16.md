## 0. 口径

### 0.1 要照的形状

用户给的南荒线形（本轮原样套到晋、宋）：

```
进入 → 调查 → 取得各方立场 → 决战／顶点 → 真正归附
                  ↑ 两段式：你赢之前各方只是「立场」（观望、偏向），赢之后才是「真正支持」
```

南荒原话：「商队进南荒 → 查清蛇彝村 → 获取花苗／白夷／碧鲮的立场 → 鬼王峒决战，打败鬼巫王 → **得到所有南荒部族的真正支持**」。

**「立场 → 归附」必须落成 event completion／派生旗，不是气氛描写。** 赢之前谁都可以偏向你、跟你做生意、甚至跟你歃血——仍不是归附。

### 0.2 顶点已定死（不要另判）

> **晋／宋／汉三条线的顶点，都是「在朝廷内获得一个特殊地位」。**

同构：太乙＝掌教之位、昭南＝得到所有南荒部族的真正支持。每条线以**得到一个身份**收束，不以打赢一场仗收束。

## 2. 晋国线

### 2.1 这条线写什么

晋国线＝建康朝堂的权力与商路归谁：

入晋看见帝室已被架空 → 查清宫变各方 → 取得相府／北府／云家的立场（分赃时你**无所得**）→ 商战决战（晋旱收粮＋广源行／龙宸旧账）→ **晋廷承认一个特许商权（正典无现成官名，见 §2.2）**。

**不写**：斩吴救卓（太乙）、卓云君调教、云如瑶昏厥／私奔揭盅（主轴血脉）、小玲儿身世（蓝图 ⏳，另挂）、沉江之后的黑魔海潜伏。

蓝图 §6 把晋写成**商战副本**（广源行系旧账、云如瑶＝岳霏、小玲儿）。本线收的是「朝廷内特殊地位」；岳霏／小玲儿不进这 10 条。广源行是决战对手，不是顶点本身。

## 3. 宋国线

### 3.1 这条线写什么

宋国线＝江州战场进临安朝堂，最后用一个宋廷名分换经营权：

卷入贾师宪清岳党 → 查清粮战与围城 → 取得相府／太尉／后宫的立场 → 纸钞落地逼退宋军、再接昭南索赔 → **礼部侍郎、通问计议使**（正典职衔）。

江州仗是调查与决战的前半，**不是顶点**。尸毒破局、宋军大溃，只证明你能赢仗；宋廷还没把交涉权给你。

**不写**：狸猫换太子正文（蓝图 ⏳，高俅密谈只留种子）、林冲刺配细账（过程）、黑魔海小瀛洲杀局（公会线）。
