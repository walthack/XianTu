## 2. 自动接轨判定

`void(lcq.event.s06_03)` 只负责召回候选分支，不足以直接激活。激活 `lcq.if_xieyi_longrest` 必须同时满足：

1. 对账 evidence 在存档记忆/最近正文接地；
2. `worldDelta` 在同一事实窗口接地；
3. `characterStates` 引用的角色 ID 存在于当前 mod canon；
4. 谢艺状态明确为 `alive`、`longrest` 或 `incapacitated`；
5. 不出现 `dead`、`missing` 等冲突状态。

不满足时只保留通用 `void`/分歧记录，不得硬塞进谢艺生还分支。若状态明确为 `missing`，运行时另写 `world.xieyi_absence.active`：这是可续玩的缺席失败后果，不是生还 IF。

## 3. 三条固定验收路线

### A. 正典路线

按原著完成围猎与谢艺之死。预期：事件正常 `done`，不生成分歧账本，不激活 if 分支，stage_07 保持死讯叙事。

### B. 谢艺生还路线

玩家救下谢艺，使其重伤长养。预期：

- `lcq.event.s06_03` 以 `void` 放行；
- 账本记录世界差异与谢艺状态；
- 激活 `lcq.if_xieyi_longrest`；
- 后续 prompt 明示“本世界线分歧”，NPC 必须据此行动；
- stage_07 孟非卿事件投影为“谢艺生还的后果”；
- 侧栏世界线记录可见本次变化。

### C. 缺席／失败路线

玩家未能介入或以其他原因使预设死亡桥段失效。若谢艺状态为 `missing`，预期：不激活 `lcq.if_xieyi_longrest`；stage_07 以“谢艺失踪的后果”替代死讯 Rail，孟非卿必须同时安排搜寻与联络线防卫。玩家可选择承担其中一项，另一项持续施压；不得确认谢艺死亡、已获救或安然无恙。

## 4. 纵切通过条件

- 三条路线各跑一次，至少形成两种结构性不同的下游局面：生还路线的接应/疗养（或黑魔海调查），与缺席路线的搜寻/联络线防卫；
- 早期选择在 20 轮内至少回响一次；
- NPC 不只复述变化，至少产生一次由分歧驱动的行动、任务或关系/势力反馈；
- 失败路线能继续推进，不要求读档重复同一动作；
- 三次运行均不死锁、不越权改写 runtime、不泄露后续正典。
