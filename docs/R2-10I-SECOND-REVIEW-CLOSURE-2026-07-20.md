# R2-10I 世界／NPC 引擎统一二审收口

日期：2026-07-20
范围：R2-10D、E、G、H 的五项反例；R2-10F 无问题，不改行为。

## 结论

统一二审指出的四项阻断与一项验收证据缺口均已转成生产合同和自动化反例。R2-10 的确定性 G1 仍成立；本收口不替代真实模型 G2，也不解锁共享服外测或默认线部署。

## 修复

1. **态度范围**：validator 对角色初始态度、行动阈值和关系 effect 强制 `-100..100`；评分、资格判断和回执读取旧档时再防御性钳位，越界旧值不能放大效用或泄漏到回执。
2. **多方冲突**：同一轮先按 `score + power` 全局稳定排序，再处理冲突图；一旦成为 `blocked`，立即退出后续比较，不能继续阻断第三方或覆盖审计对象。
3. **机会追踪寿命**：每张卡保留首次 `trackedAtTurn`。切换追踪只改变当前选择，不清除首次追踪时间；达到六回合上限时，`tracked` 卡显式转为 `expired`、退出 UI 选择并拒绝重追。
4. **确定性遍历**：所有参与评分的 map/object 在累加前按 key 排序；可选 wake 字段先去除 `undefined` 再参与唤醒和哈希，使内存对象与 JSON 重载对象得到相同 `inputHash` 和完整输出。
5. **跨书证据**：清羽与云龙均执行真正的 JSON stringify/parse 往返；连续三轮调用生产 runtime 后比较整份存档字节串及决策哈希。两条未参与路线均明确断言零权限。
