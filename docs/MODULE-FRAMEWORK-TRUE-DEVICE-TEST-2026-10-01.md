## 一、这轮要回答的问题

1. 模块链路的回合，**等待时间**是否明显短于原链路？（目标是每回合 ≤30 秒，本轮只记录，不作为通过门槛）
2. 剧情演出失败时，是否**先重试、再回落原链路**，而不是直接报错卡住？
3. 回合记忆是否正常工作：下一回合的正文**承接得上**上一回合？
4. 给「行动解释」「剧情演出」单独换模型后，**是否真的换了、且不影响别的功能**？
5. 后台审计开着时，**玩家完全感觉不到它**，同时它确实在本地留下了日志？

## 四、测试项

每项都按"操作 → 看什么 → 记什么"。观察者按第五节的表逐回合记。

### T1 设置页（约 3 分钟）
- **操作**：打开「回合模块模型」，看四行；给「行动解释」换一个连接，再改回「继承」。
- **看**：四行都在；每行的「当前：……」写明了继承谁、实际是哪个模型；改动后刷新页面，选择仍在。
- **通过**：显示与选择一致，刷新后不丢。

### T2 模块演出常规回合（核心）
- **操作**：走到能用合同动作的地方（例如苏妲己谈期限），用建议动作或自然输入，如「我用霓龙丝产地线索换三个月期限。」
- **看**：HUD 显示「本轮模块演出 · X 秒 · 输入 Y 字」；演出模型名正确，继承的会标「继承」。
- **记**：前台秒数（HUD 上的数字 + 观察者自己掐表）；正文是否通顺、是否替玩家做了决定、是否把没谈成的事写成谈成了。
- **通过**：正文正常出现，可以继续操作，正文没有越过本轮应有的结果。

### T3 失败重试与回落
- 真实模型下不一定能触发，**不需要刻意制造**，遇到就记。
- **看**：HUD 出现「模块演出 2 次未通过，本轮回落原链路：<原因>」，正文照常出现。
- **记**：原因原文、这一回合的总等待时间。
- **不通过的信号**：直接报错、输入框被清空、卡住不动。

### T4 回合记忆与下一回合承接
- **操作**：一个模块演出回合结束后，**等十几秒**再展开 HUD；然后再做下一个动作。
- **看**：HUD「回合记忆：accepted（已替换为短期记忆摘录）」；下一回合正文能接上上一回合的事。
- **追加一次快速连发**：上一回合正文一出来就立刻发下一句，不等记忆。再下一回合时看上上回合的记忆是否也变成了 accepted（迟到结果应排队补上，不应丢）。
- **记**：记忆状态（pending / accepted / rejected / failed / disabled）、承接是否断裂。

### T5 行动解释
- **操作**：用一句不那么明确的自然输入，例如「我想先四处看看，再琢磨下一步」。
- **看**：要么被识别为某个动作，要么提示你说得更具体（输入框里的字还在）。
- **记**：从按回车到出现结果/提示的等待时间；有没有识别错（把 A 意图当成 B 动作执行了）。

### T6 后台审计（对玩家不可见）
- **操作**：正常连续玩 **至少 6 个回合**（首次见到存档时从当前进度起算，满 5 个新回合才第一次审计）。之后回到 API 管理页，「后台审计」那一行会显示「本地日志 N 条」，点「导出日志」。
- **看**：玩的过程中**完全没有**审计相关的提示或卡顿；导出的 JSON 里有条目，`status` 为 accepted / rejected / failed 之一。
- **记**：日志条数；如果有 `findings`，挑 2–3 条看看说得对不对（对 / 不对 / 说不清），这是本轮最想要的反馈之一。
- **不通过的信号**：审计期间发出的回合明显变慢、正文或存档里出现审计内容。

### T7 存档、刷新、续玩
- **操作**：在一个模块回合之后正常保存退出 → 刷新页面 → 继续落地连续档。
- **看**：正文、当前目标、HUD 记忆状态都还在；没有重复结算（同一件事没被算两次，东西没多给一次）。

### T8 中途切档（可选）
- **操作**：模块回合刚结束、记忆还是 pending 时，切到另一个存档，再切回来。
- **看**：另一个存档里没有出现这一档的内容。

## 七、已知限制（看到不用报）

- 自由交谈、判定、机会卡、拒赌专用动作等走原链路，HUD 显示「原链路」。
- 原链路自身的慢、截断等老问题本轮没有修，照常记录但标注"原链路"。
- 审计结论只是线索，可能有误，本轮的目的就是看它说得准不准。
- 剧情演出被拒收后会消耗重试；回合总时长上限 60 秒，超时会提示手动重试，输入保留。
