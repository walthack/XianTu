## 5. 文本门禁修复范围

门禁测试不能只覆盖阿拉伯数字和“某某之死”的固定短语。真机至少暴露以下变体：

- 中文兵力/距离/比例：`三百甲士`、`三百弟兄`、`八校尉`、`三十人`、`三十步`、`五十步`、`四十三步`、`七尺`、`增税三成`
- 未揭露组织/秘密：`黑魔海`、黑魔海暗桩、魂丹交换、暗道、伏兵
- 未揭露人物/后续：`吕冀`、董卓后续死亡措辞
- 预训练补造的具体参与者、交换条件和军队部署

关键词扫描须结合语境，不能把普通的“一名宫女”误报为兵力数字；应优先匹配“数词 + 军事单位/距离/比例”及明确禁名。
